# Ripple Field Simulation Package

This repository includes:
- `RippleNet_Colab_Starter.ipynb`: Jupyter/Colab notebook demonstrating the simulation of Directed Entropic Ripples using synthetic data.
- `/data/synthetic/`: Placeholder for mock EEG–HRV datasets.
- `/figures/`: Directory for exported figures usable in TeX.
- `/src/`: For Python modules or helpers in the future.

**NOTE:** This version uses structured synthetic data for demonstration only.
Empirical validation with real EEG/HRV signals is under development.

## Colab Integration
To run the simulation in Google Colab, open the notebook and execute each cell sequentially.
