
# 🔬 Ripple Field Simulation (3D, Multi-Node)

This repository contains a Python-based simulation of the **Ripple Field Theory**, as proposed in:

**“Node-Induced Informational Perturbations: A Framework for Directed Entropic Ripples in Probabilistic Fields”**  
*Palapol Chobisara, Field Intelligence Lab, 2025*

---

## 📌 Overview

This simulation models how coherent agents (nodes) emit non-energetic **entropy gradients** ("ripples") into a shared informational field. The ripple alters the **probabilistic curvature** of the field without requiring energy transfer—demonstrating a physically grounded mechanism of **nonlocal causal influence**.

---

## 🧠 Key Concepts Modeled

- **Ripple** = Gradient of entropy × coherence (∇H × C)  
- **Field** = Log-probability landscape (Φ) updated via Laplacian smoothing  
- **Nonlocal Influence** = Nodes bias the field probabilistically across space  
- **Constructive Interference** = Multiple nodes form coherent attractors

## 📈 What’s Included

- `ripple_simulation_3d.ipynb` – Jupyter notebook of 3D field simulation with 3 nodes

---

## 🚀 How to Use

1. Install dependencies:  
   ```bash
   pip install numpy matplotlib
   ```

2. Open the notebook in Jupyter:
   ```bash
   jupyter notebook ripple_simulation_3d.ipynb
   ```

3. Run all cells. You will see a 3D visualization of ripple propagation from multiple nodes across time.
